## Ranh giới V1/V2
DEALZ V2 là dự án mới trên WordPress mới. Không tái sử dụng mã nguồn, database, theme, plugin, menu hoặc cấu trúc V1 nếu chưa được đánh giá và phê duyệt riêng.

## Năm ưu tiên trước khi code song song
1. Rà soát phạm vi MVP và các quyết định còn mở.
2. Khóa mô hình dữ liệu và migrations.
3. Khóa REST API contracts, quyền truy cập và trạng thái nghiệp vụ.
4. Thiết lập GitHub, branch protection, PR và quy trình handoff.
5. Chia milestone/ticket theo dependency; chỉ triển khai song song sau khi contract nền tảng được duyệt.

Bộ tài liệu là đặc tả và kế hoạch triển khai. Nó không chứng minh repository, website, hosting, API keys, thanh toán hoặc source code đã được tạo hay triển khai.
